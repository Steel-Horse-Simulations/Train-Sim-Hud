Safety systems

Scans CurrentDrivableActor for any node whose name looks like a safety system (AWS, TPWS, PZB, Sifa, vigilance, cruise control, etc.) and also probes a list of known candidate paths to see which ones this loco responds to. Run while in an active driving session with a loco loaded. Once you've found the right paths, "Enable all found" sends Value=true to each one that responded.

Scan the game's API

This walks every node the game currently exposes (via /info and /list) and builds a full text map of every endpoint — which ones are readable, which are writable, and the exact path to call. It only changes with your loco/route/session, so re-run it any time you want an up-to-date picture. Nothing here is sent anywhere automatically — copy or save the result yourself and paste it to Claude when you want a new dashboard built around it.

Raw response (bypasses all parsing)

If Scan keeps coming back empty even though the game is clearly responding, this shows the exact, unprocessed JSON the game sends back for a given path - no interpretation on our end at all. This is the most reliable way to see the real shape of the data so it can be matched exactly, instead of guessing again.
