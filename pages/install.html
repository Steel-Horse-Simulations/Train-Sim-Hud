Add to Home Screen

Tap one below to open it, then use the install prompt (or your browser's own "Add to Home screen" option) to pin it as its own full-screen app icon - no browser address bar, same as a native app. The Dashboard still needs this PC reachable on your network to show live data once opened; Timetables and Train Classes work from whatever's already been synced, even if the PC isn't reachable right now.
