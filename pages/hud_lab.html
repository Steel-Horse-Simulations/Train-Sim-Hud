HUD Lab

A sandbox for trying out new gauge/panel ideas against live data, before anything gets added to the real Dashboard. Nothing here can affect the main Dashboard - this is a separate page. Workflow: watch a live value here to confirm what it actually shows and how it should be scaled → preview the panel design → then it gets built into the real Dashboard.

Live API path watchers

Add a CommAPI path (same format as the Discovery page, e.g. CurrentDrivableActor.Function.HUD_GetAmmeter) to watch it continuously at the same rate as the real Dashboard (300ms) - useful for confirming a new gauge's scaling/meaning against the real thing before building anything. Add as many as you like at once; each gets its own pill below and keeps updating independently. Click a pill to see its raw response.

No experimental panels added yet. Once a panel design is ready to try against real live data (e.g. an Ammeter gauge), it gets built here first, using the watchers above to confirm the real values, before it's ever added to the actual Dashboard.
