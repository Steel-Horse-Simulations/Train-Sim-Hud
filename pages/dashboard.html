This is the Desktop HUD (optimized for 1920×1080). It's kept visually and functionally identical to the Tablet HUD - any change requested for one applies to both. This page polls the game once every couple seconds while it's running. If you don't see values, make sure the game is launched with -HTTPAPI, you're in an active driving session, and the key folder is set correctly on the Setup page.
