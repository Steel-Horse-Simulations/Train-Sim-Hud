This is the Tablet HUD (optimized for the Samsung Galaxy Tab A11's 1340×800 landscape display). It's kept visually and functionally identical to the Desktop HUD - any change requested for one applies to both. This page polls the game once every couple seconds while it's running. If you don't see values, make sure the game is launched with -HTTPAPI, you're in an active driving session, and the key folder is set correctly on the Setup page.
