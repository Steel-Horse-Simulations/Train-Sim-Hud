Connection

Checking…

The game must be running with the -HTTPAPI launch option set (Steam → right-click Train Sim World → Properties → Launch Options), and you should be in an active session for most endpoints to respond.

API key folder

This is the folder that contains CommAPIKey.txt — normally Documents\My Games\TrainSimWorldX\Saved\Config. The app reads the key from here every time it talks to the game; it's never typed in by hand.

API address

Only change this if you've configured TSW to use a non-default port.

Real timetables & train classes (TSW HUD app)

Automatically finds and imports real timetable/train-class data from the other "TSW HUD" app's own database, in the background, so Timetables and Train Classes stay current without any manual copying. Checks on startup and roughly every 15 minutes after that.

Checking…

Auto-detection scans common folders (Downloads, Desktop, Documents) for the other app's database. If it can't find it, or found the wrong one, paste the correct path to tsw_hud.db above.

HTTPS Certificate

Offline sync on other devices (see HTTPS_SETUP.md) needs a certificate that expires every couple of years. Important limitation: once it's actually expired, browsers block the connection outright before this page can even load to show a warning - so this can only ever be a useful heads-up before that happens, not an after-the-fact alert. Check back here occasionally, especially if it's been a year or two since you set it up.

Open on another device (tablet, phone)

Works over your local Wi-Fi/network only — not the internet. Make sure your tablet is on the same Wi-Fi network as this PC, then open one of these addresses in its browser. If this PC has a VPN active, you may see extra addresses that won't work — the one matching what your router shows for this PC (often 192.168.x.x) is the one to use.

Diagnostics

If the app hangs or seems stuck, click this and copy the result to send to Claude — it shows exactly how long each recent request to the game took, which pinpoints whether the slowdown is the game, the network, or the app itself.
