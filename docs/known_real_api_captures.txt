================================================================================
CASE-INSENSITIVE KEY LOOKUP PATTERN
================================================================================
The game API returns field names inconsistently (SpeedLimit, speedlimit, etc.).
Always use this helper:

  def _get_ci(d, keys, default=None):
      """Case-insensitive dict key lookup. Tries each key in order."""
      if not isinstance(d, dict):
          return default
      lower_map = {k.lower(): v for k, v in d.items()}
      for key in keys:
          val = lower_map.get(key.lower())
          if val is not None:
              return val
      return default

Usage: speed_limit_ms = _get_ci(values, ["SpeedLimit", "speedlimit", "speed_limit"])
