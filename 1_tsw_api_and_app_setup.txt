TSW API & BASIC APP SETUP
=========================

WHAT THE TSW API IS
--------------------
Train Sim World exposes a local HTTP API when launched with -HTTPAPI as a
Steam launch option. It runs on:
  http://127.0.0.1:31270

Every request must include the auth header:
  DTGCommKey: <key>

The key is found in a text file. Common locations across TSW versions:
  %USERPROFILE%\Documents\My Games\TrainSimWorld6\Saved\Config\CommAPIKey.txt
  %USERPROFILE%\Documents\My Games\TrainSimWorld4\Saved\Config\CommAPIKey.txt
  (and equivalent for TSW2, TSW3, TSW5)
The filename is CommAPIKey.txt or DTGCommKey.txt depending on the guide.
Read the first line of whichever file is found.

Use 127.0.0.1 explicitly, not "localhost" — on some Windows setups "localhost"
triggers an IPv6 attempt that silently times out before falling back to IPv4,
adding ~2s to every request.

API VERBS
---------
GET  /info                    → metadata about the running game/API version
GET  /list                    → root node list
GET  /list/<path>             → list children of a node
GET  /get/<path>              → read a value or call a Function.*
PATCH /set/<path>             → write a value (not all nodes are writable)

Response shape:
  { "Result": "Success", "Values": { ... } }
or
  { "Result": "Error", "Message": "..." }

DISCOVERY - FINDING NEW ENDPOINTS
-----------------------------------
Start at /list to get the root nodes, then recurse into /list/<node>.
Call /get/<path> on leaf nodes to see their current values.
Key root nodes: CurrentDrivableActor, CurrentFormation, DriverAid, WeatherManager,
TimeOfDay, and more. These only respond when in an active driving session.

Function.* nodes are callable — GET /get/Path.To.Function.FunctionName returns
the function's result under { "Values": { "ReturnValue": ... } }.

CONFIRMED VALUE SHAPES AND UNITS
----------------------------------
All speed values from the API are in METRES PER SECOND (m/s).
  mph = m/s * 2.23694
  kph = m/s * 3.6

Distance: DriverAid.Data.distanceToSignal is in CENTIMETRES (not metres).
  Confirmed: raw value 7379 = 73.79m = ~81 yards (matched real in-game display).
  Conversion: metres = rawCm / 100

Speed limit raw value: DriverAid.Data.speedLimit.value is in m/s.
  Guard against Unreal's "unset float" sentinel: treat any value >= 112 m/s
  (~250mph) as "not yet set" rather than a real limit.

Gradient: DriverAid.Data.gradient is already a percentage (e.g. 0.2 = 0.2%).
  Do NOT multiply by 100 — it's not a 0-1 fraction.

Weather values (WeatherManager.Data): Temperature in Celsius, Precipitation
/ Cloudiness / FogDensity are 0-1 fractions — multiply by 100 for percentage.

Function.* return value: HUD_GetSpeed returns under Values.ReturnValue (not
"Speed (ms)" as some older code assumed).

BASIC APP STRUCTURE
--------------------
The app is a Python Flask server (app.py) with HTML/JS pages in pages/.
The server proxies API calls so pages never need the key or worry about CORS.

Minimum requirements.txt:
  flask>=3.0
  requests>=2.31

Minimum app.py structure:
  import os, json, requests
  from flask import Flask, jsonify, send_from_directory, request

  app = Flask(__name__)
  APP_DIR = os.path.dirname(os.path.abspath(__file__))
  PAGES_DIR = os.path.join(APP_DIR, 'pages')
  CONFIG_FILE = os.path.join(APP_DIR, 'config.json')
  DEFAULT_API_BASE = 'http://127.0.0.1:31270'

  def load_config():
      try: return json.load(open(CONFIG_FILE))
      except: return {}

  def save_config(cfg):
      json.dump(cfg, open(CONFIG_FILE, 'w'), indent=2)

  CONFIG = load_config()

  def read_api_key():
      folder = CONFIG.get('key_folder', '')
      for name in ['CommAPIKey.txt', 'DTGCommKey.txt']:
          path = os.path.join(folder, name)
          if os.path.isfile(path):
              key = open(path).read().strip()
              if key: return key, path
      return None, None

  def api_headers():
      key, _ = read_api_key()
      return {'DTGCommKey': key} if key else None

  def api_get(path, timeout=(2, 3)):
      headers = api_headers()
      if not headers: return {'error': 'no_key'}, 400
      base = CONFIG.get('api_base', DEFAULT_API_BASE).replace('localhost', '127.0.0.1')
      try:
          r = requests.get(f'{base}/{path.lstrip("/")}', headers=headers, timeout=timeout)
          return r.json(), r.status_code
      except Exception as e:
          return {'error': str(e)}, 503

  @app.route('/')
  def index():
      return send_from_directory(PAGES_DIR, 'index.html')

  @app.route('/pages/<path:filename>')
  def pages(filename):
      return send_from_directory(PAGES_DIR, filename)

  @app.route('/api/config', methods=['GET'])
  def get_config():
      key, key_path = read_api_key()
      return jsonify({'key_folder': CONFIG.get('key_folder', ''), 'key_found': bool(key)})

  @app.route('/api/config', methods=['POST'])
  def set_config():
      body = request.get_json(force=True) or {}
      if 'key_folder' in body: CONFIG['key_folder'] = body['key_folder']
      save_config(CONFIG)
      return jsonify({'ok': True})

  @app.route('/api/proxy/get/<path:subpath>')
  def proxy_get(subpath):
      body, status = api_get(f'get/{subpath}')
      return jsonify(body), status

  if __name__ == '__main__':
      app.run(host='0.0.0.0', port=5000, debug=False)

DYNAMIC PAGE REGISTRY (add this so new pages auto-appear in nav later)
-------------------------------------------------------------------------
Create pages/registry.json:
  [
    {"id": "setup", "name": "Setup", "url": "/", "dev_only": false, "order": 0}
  ]

Add a Flask route to serve it:
  @app.route('/api/pages')
  def api_pages():
      return send_from_directory(PAGES_DIR, 'registry.json')

Create pages/nav.js:
  (async function() {
    const el = document.getElementById('navContainer');
    if (!el) return;
    const items = await fetch('/api/pages').then(r => r.json());
    items.sort((a, b) => a.order - b.order);
    const path = location.pathname;
    el.innerHTML = items.map(it => {
      const active = it.url === path || (it.url !== '/' && path.endsWith(it.url.split('/').pop()));
      return `<a href="${it.url}"${active ? ' class="active"' : ''}>${it.name}</a>`;
    }).join('');
  })();

Every page with a nav bar includes:
  <div class="nav" id="navContainer"></div>
  <script src="/pages/nav.js"></script>

To add a new page: add an entry to registry.json. No HTML changes needed elsewhere.

SETTINGS PAGE (pages/index.html) MINIMUM CONTENT
--------------------------------------------------
  <div class="topbar">
    <div class="brand"><strong>TSW HUD</strong></div>
    <div class="nav" id="navContainer"></div>
  </div>
  <main>
    <div class="panel">
      <h2>API Key Folder</h2>
      <div class="field-row">
        <input type="text" id="folderInput" placeholder="Paste folder path here">
        <button class="btn primary" onclick="saveFolder()">Save</button>
      </div>
      <p id="keyStatus" class="small dim">Checking...</p>
    </div>
  </main>
  <script src="/pages/nav.js"></script>
  <script>
    async function saveFolder() {
      await fetch('/api/config', {
        method: 'POST',
        headers: {'Content-Type': 'application/json'},
        body: JSON.stringify({ key_folder: document.getElementById('folderInput').value })
      });
      checkStatus();
    }
    async function checkStatus() {
      const cfg = await fetch('/api/config').then(r => r.json());
      document.getElementById('folderInput').value = cfg.key_folder || '';
      document.getElementById('keyStatus').textContent = cfg.key_found ? 'Key found.' : 'Key not found.';
    }
    checkStatus();
  </script>
