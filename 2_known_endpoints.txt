TSW API - CONFIRMED ENDPOINTS
==============================
All confirmed via real in-game captures. All speeds in m/s unless stated.

VEHICLE / LOCO DETECTION
--------------------------
GET /get/CurrentDrivableActor.ObjectClass
  → { Values: { ReturnValue: "RVM_ClassName_C" } }
  Raw object class string. Not always human-readable.

GET /get/CurrentFormation/0.Function.IS_GetVehicleInfo
  → { Values: { VehicleInfoResult: { DisplayName: "...", MaxSpeed: <m/s>, ... } } }
  Clean display name and metadata. Fails when no loco is loaded.

GET /get/DriverAid.Data
  → { Values: {
      formationMaxSpeed: <m/s>,      ← loco formation max speed
      gradient: <float>,             ← already %, NOT 0-1 (e.g. 0.2 = 0.2%)
      speedLimit: { value: <m/s> },  ← current track speed limit (m/s)
      distanceToSignal: <float>,     ← CENTIMETRES (divide by 100 for metres)
      signalAspectClass: "...",      ← e.g. "Clear", "Caution", "Danger"
      nextSpeedLimits: [             ← upcoming limit changes
        { value: { value: <m/s> }, distanceToNextSpeedLimit: <cm> },
        ...
      ]
    } }

SPEED
------
GET /get/CurrentDrivableActor.Function.HUD_GetSpeed
  → { Values: { ReturnValue: <m/s> } }
  300ms poll rate used in the main HUD. ReturnValue is the field name
  (not "Speed (ms)" as some older code assumed).

POSITION / MAP
---------------
GET /get/DriverAid.PlayerInfo
  → { Values: {
      geoLocation: { latitude: <float>, longitude: <float> }
    } }
  Real-world GPS coordinates. Updates as the train moves.

WEATHER (in-game)
------------------
GET /get/WeatherManager.Data
  → { Values: {
      Temperature: <celsius>,
      Precipitation: <0-1 fraction>,
      Cloudiness: <0-1 fraction>,
      FogDensity: <0-1 fraction>
    } }

TIME OF DAY
------------
GET /get/TimeOfDay.data
  → { Values: {
      LocalTimeISO8601: "2025-07-28T14:32:00",
      SunriseTime: "04:45",
      SunsetTime: "21:12"
    } }

AMMETER (electric locos only)
------------------------------
GET /get/CurrentDrivableActor.Function.HUD_GetAmmeter
  → { Values: { Amps: <raw amps> } }
  Divide by 1000 for kA. Confirmed: real traction ammeter shows 0-8 kA range.
  API returns raw amps (e.g. 3531 = 3.531 kA).

BRAKE GAUGES
-------------
GET /get/CurrentDrivableActor.Function.HUD_GetBrakeGauge_1
GET /get/CurrentDrivableActor.Function.HUD_GetBrakeGauge_2
  Which is brake pipe vs. main reservoir has NOT yet been determined.
  PSI scaling NOT yet confirmed. Use the HUD Lab page to compare both
  values against the physical in-cab gauges while driving to confirm.

DISCOVERY - LISTING NODES
---------------------------
GET /list
  Root-level nodes (changes depending on what's loaded in-game).

GET /list/CurrentDrivableActor
  All properties and sub-paths of the current loco.

GET /list/<any.path>
  Enumerate any node. Use this to find new endpoints.

GET /info
  API and game version metadata.

UNIT REFERENCE
---------------
Speed:           m/s from API  →  * 2.23694 = mph  /  * 3.6 = kph
Distance:        cm from API   →  / 100 = metres  /  * 0.01 * 0.000621371 = miles
Gradient:        already %     →  display as-is (do NOT multiply by 100)
Speed limit:     m/s           →  guard: ignore if >= 112 (Unreal sentinel)
Amps:            raw amps      →  / 1000 = kA
Weather ratios:  0-1 fraction  →  * 100 for %
